 **Past Work**
---
* **Arcade Game for Judd (2023):** Designed and built an automated, adaptive arcade ball return system for a 5-year-old with cerebral palsy. 
  * *Award:* Best Use of 3D Printing, [Make:able 2023](https://weareprintlab.com/blog/makeable-2023-winners-announcement/).
  * *Video:* [2-min build video on Vimeo](https://vimeo.com/828721050).

* **Arm Attachment for Joshua (2024):** Engineered a lightweight, customizable arm attachment utilizing generative design to help a student hold objects and catch a ball.
  * *Award:* Swept both Best Use of 3D Printing & Best Use of Autodesk Software, [Make:able 2024](https://weareprintlab.com/blog/makeable-2024-winners/).

 * **Game Board For Kori (2025):** While no awards were won for this project, Kori still got a custom-designed busy board, and it was the first step out of mechanical design and into electrical design.

* **Coordination Games for Steven (2026):** Modeled and refined interactive, stabilized physical games in Autodesk Fusion to help a young man with cerebral palsy improve hand-eye coordination through play.
  * *Award:* Best Use of Autodesk Software, [Make:able 2026](https://weareprintlab.com/blog/the-2026-makeable-challenge-winners/).
